## Установка

```bash
python -m venv .venv
source .venv/bin/activate         # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск
http://localhost:8000/

## Что реализовано в MVP

✅ Медочай (состав: мёд, чай, вода, плотность)  
✅ База-лимонадница (объём медочая + стартера, pH, F1 start/end)  
✅ Бутылки (объём, подпись или авто-номер, стадия)  
✅ Жизненный цикл: F1 → розлив → F2 → F3 → хранение → выпито/выброшено  
✅ Пошаговый ввод замеров (pH, Brix, t°) — по одному значению  
✅ Индикаторы стадий  
✅ Бэкап по кнопке, 3 последних, экспорт/импорт  
✅ Мобильный UI  

## Что НЕ реализовано (обсудим на след. шаге)

- Поля этапов детально (по твоим алгоритмам)
- Индикатор напоминаний (жёлтая точка) — заложу, когда определим интервалы
- Гибкая маршрутизация жизненного цикла (сейчас кнопки стадий — жёсткие, но работают)
